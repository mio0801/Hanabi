## ⚡ コマンドプロンプトでのビルド・実行手順

MSVCのコンパイラ（`cl`）を使ってコマンドプロンプトでビルド・実行する手順です。

### 1. 「開発者コマンドプロンプト」を起動する
`cl` コマンドは通常のコマンドプロンプトでは使用できません。Windowsのスタートメニューから以下のいずれかを起動してください：
- **「Developer Command Prompt for VS 2022」** （またはお使いのVSのバージョン）
- **「x64 Native Tools Command Prompt for VS 2022」**

### 2. プロジェクトフォルダに移動する
コマンドプロンプトで以下のコマンドを実行し、このフォルダに移動します：
```cmd
cd /d "C:\Users\kanmi\OneDrive - 東京都市大学 Tokyo City University\3年\sample\saisyukadai2"
```

### 3. ビルドと実行をする
フォルダ内にある便利な一括ビルド用スクリプト `build.bat` を実行します：
```cmd
build.bat
```
このスクリプトを実行すると、自動的に `cl` でコンパイルを行い、コンパイル成功後にアニメーション（`MinimalNostalgia.exe`）が自動で起動します。

---

## 🛠️ 手動でコンパイルする場合のコマンド
`build.bat` を使わずに手動でコンパイルする場合は、以下のコマンドを実行してください：
```cmd
cl main2.c /I. /D_CRT_SECURE_NO_WARNINGS /O2 /Fe:MinimalNostalgia.exe
```

## 🎮 キーボード・マウス操作 / Controls

* **[マウス左ドラッグ]** : 視点を360度シームレスに回転させます。
* **[スペースキー (Space)]** : **花火を今すぐ打ち上げます！** 同時に少し夜風が吹き抜けます。
* **[f] / [F]** : フルスクリーンとウィンドウモードの切り替え。
* **[w] / [s]** : ズームイン / ズームアウト。
* **[矢印キー]** : 手動でのアングル微調整。
* **[Esc] / [q]** : 終了します。
