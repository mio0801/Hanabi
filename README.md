# MinimalNostalgia2

OpenGL を用いて制作した和風空間 CG 作品です。
行燈・障子・畳・背景の民家・山並みなどを描画し、夜の日本風景を表現しています。

--------------------------------------------------------------------------------------
# Features

* 和風室内空間の描画
* 行燈による暖色ライティング
* 障子テクスチャ
* 畳テクスチャ
* 星空背景
* 日本風の山並み
* 背景の民家
* OpenGL ライティング
* 花火アニメーション
* 炎のゆらぎ表現

# Scene Description

この作品では、日本の古民家風の室内空間を OpenGL により表現しています。
室内には、
* 畳
* 障子
* 行燈
* ちゃぶ台
* スイカ
などを配置しています。

また背景には、
* 山並み
* 星空
* 日本風の民家
を配置し、夜の静かな日本風景を再現しました。

行燈の炎には時間変化を利用したゆらぎアニメーションを追加しています。

さらに、スペースキーによって花火を打ち上げることができます。

---------------------------------------------------------------------------------------------------

# Technical Points

* OpenGL のライティング機能を利用
* テクスチャマッピングを使用
* glMaterial による質感調整
* glPushMatrix / glPopMatrix による階層管理
* アニメーション処理
* 背景オブジェクトの遠景表現

# Build Instructions

## Required Libraries

* OpenGL
* FreeGLUT

---------------------------------------------------------------------------------------------------

## Visual Studio Setup

1. Visual Studio 2022 をインストール
2. C++ Desktop Development を有効化
3. FreeGLUT を導入
4. プロジェクトに以下を追加

### Include Directories

GL/

### Link Libraries

opengl32.lib
glu32.lib
freeglut.lib
---------------------------------------------------------------------------------------------------

## Build

Visual Studio で

Ctrl + Shift + B　　を押してビルドしてください。

---------------------------------------------------------------------------------------------------

## Run

F5　　で実行できます。
